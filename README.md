# keuangan-spp

Aplikasi Sistem Informasi Pembayaran & Manajemen SPP Bulanan Sekolah.

## Fitur Utama
- **Modul 1: Manajemen Data Siswa**: Pengelolaan data siswa, kelas, tarif SPP, dan status pembayaran.
- **Modul 2: Transaksi Pembayaran**: Pembayaran SPP (Tunai, Transfer Bank BSI/BCA, QRIS), cetak kuitansi struk, dan pencatatan petugas.
- **Modul 3: Tunggakan & Laporan**: Rekapitulasi tunggakan, cetak surat penagihan, dan ekspor laporan.
- **Modul 4: Pengaturan & Sistem**: Konfigurasi sekolah, backup/restore data, dan log aktivitas.

## Teknologi
- React 19 + TypeScript
- Vite
- Tailwind CSS
- Firebase Firestore
- Lucide React & Motion

## Cara Menjalankan Secara Lokal
```bash
npm install --legacy-peer-deps
npm run dev
```
Buka browser di `http://localhost:3001` (atau port yang tertera).
